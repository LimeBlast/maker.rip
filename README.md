# maker.rip

Jekyll 4 blog. Posts imported from [2019-06-02.maker.limeblast.co.uk](https://github.com/LimeBlast/2019-06-02.maker.limeblast.co.uk).

```bash
bundle install
bundle exec jekyll serve --livereload
```

No Node, no Sass, no JS: one hand-written CSS file using native nesting, `light-dark()` dark mode,
`initial-letter` drop caps, `aspect-ratio` embeds and cross-document view transitions.
