# maker.rip

Jekyll blog using the [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) theme (based on [chirpy-starter](https://github.com/cotes2020/chirpy-starter)).
Posts imported from [2019-06-02.maker.limeblast.co.uk](https://github.com/LimeBlast/2019-06-02.maker.limeblast.co.uk).

```bash
bundle install
bundle exec jekyll serve --livereload
```

- Posts: `_posts/`, images: `assets/img/YYYY/MM/`. Set `image:` in front matter for the card/header photo.
- Sidebar pages: `_tabs/`. Site settings: `_config.yml`.
- To override a theme file, copy it from `bundle info --path jekyll-theme-chirpy` into the same path here.
